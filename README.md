# NFL Dynasty Snap Dashboard — Dad

Same dashboard structure as the existing NFL Dynasty Snap Dashboard, configured for four MFL teams:
- EGS PRO — league 73667, franchise 0005
- EGS SIM — league 67057, franchise 0003
- EGS SFX — league 62923, franchise 0003
- MLS Dynasty League — league 41969, franchise 0021

Features:
- consolidated ownership across all four leagues
- offense and IDP snap counts / percentages
- weekly history
- 3-week and season averages
- role risers/fallers
- clickable player detail drawer
- daily GitHub Actions refresh
- MFL roster refresh + nflverse/PFR snap data
